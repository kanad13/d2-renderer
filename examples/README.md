# Example D2 Diagrams

This directory contains reference D2 diagram source files and instructions for rendering them using the `d2-renderer` microservice.

---

## Directory Contents

| File | Type | Description |
| :--- | :--- | :--- |
| [architecture.d2](./architecture.d2) | Architecture Diagram | Multi-tier service topology with containers, databases, and custom styling. |
| [sequence.d2](./sequence.d2) | Sequence Diagram | OAuth 2.0 authorization code flow with actors, lifelines, and return messages. |
